# COVID-19 Dashboard
By Lizzy Mikhari

## What is this project?
This dashboard shows COVID-19 data for 5 countries from 1 Feb 2020 to 31 March 2020.
It helps to compare how COVID-19 spread in different countries.

## Countries included
- China
- Italy
- South Korea
- United States (US)
- South Africa

## Data Source
Johns Hopkins CSSE COVID-19 Data Repository

## What does the dashboard show?
- Metric Cards: Total Confirmed, Deaths, Recovered for the selected country
- Line Chart: Confirmed cases over time
- Bar Chart: Confirmed cases by country
- Dropdown: Choose a country to update the cards and line chart

## How to use it
1. Open the live link below
2. Choose a country from the dropdown
3. Watch the cards and charts change
